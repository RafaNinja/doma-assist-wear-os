# ⌚ Doma Assist

Aplicativo desenvolvido para **Wear OS** como projeto acadêmico.

## 📌 Sobre o projeto

O **Doma Assist** é uma aplicação para smartwatch desenvolvida com Android Studio, Kotlin e Android SDK, com o objetivo de disponibilizar funções relacionadas ao gerenciamento e à reprodução de áudio diretamente no dispositivo Wear OS.

## ⚙️ Funcionalidades

- 🔊 Verificação da disponibilidade do alto-falante;
- 🎧 Verificação de dispositivo Bluetooth de áudio;
- ⚙️ Acesso às configurações de Bluetooth;
- ▶️ Reprodução de áudio armazenado localmente;
- ⌚ Interface adaptada para tela circular de smartwatch;
- ↕️ Rolagem vertical utilizando `ScrollView`.

## 🛠️ Tecnologias utilizadas

- Kotlin
- Android Studio
- Android SDK
- Wear OS
- Gradle
- XML
- AndroidX
- MediaPlayer
- Git / GitHub

## 🏗️ Arquitetura atual

O projeto utiliza uma estrutura Android tradicional baseada em `Activity`.

### 🧩 MainActivity

Responsável pela interface e pela interação com o usuário, incluindo os eventos dos botões de verificação, Bluetooth e reprodução de áudio.

### 🔊 AudioHelper

Responsável pela verificação dos dispositivos de saída de áudio, incluindo alto-falante interno e Bluetooth.

### 📁 Recursos

Os elementos visuais estão implementados em XML e o áudio utilizado nos testes está armazenado em `res/raw`.
